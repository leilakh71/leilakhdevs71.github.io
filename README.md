# 🌸 Liara Beauty – Online Beauty Store

Liara Beauty is a modern and responsive beauty e-commerce website built with **Next.js, React, and MongoDB**.

The project is designed to provide a beautiful and user-friendly shopping experience for beauty, skincare, cosmetics, and personal care products.

## 🚀 Technologies Used

- **Next.js** – React framework
- **React.js** – Building reusable UI components
- **JavaScript** – Application logic
- **MongoDB** – Database management
- **Tailwind CSS** – Responsive styling
- **JWT & Cookies** – Authentication

## ✨ Features

- Modern and elegant UI design
- Responsive layout for all devices
- Light and Dark Mode
- Product categories and product listings
- Shopping cart and wishlist
- User authentication
- Admin dashboard
- User panel
- Product management
- RTL and Persian language support
- Interactive animations

## 🎨 Design

- Modern beauty and skincare aesthetic
- Pink and cream color palette
- Clean and responsive layouts
- Smooth animations and transitions

## 🛠️ Project Goals

- Building a full-stack e-commerce application
- Improving Front-End and Back-End development skills
- Working with databases and authentication
- Creating reusable and maintainable components
- Developing a professional online shopping experience
